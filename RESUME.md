# Resume Project Entry

## Currency API — MuleSoft Integration Project

**Role:** MuleSoft Developer / Integration Engineer

**Technologies:** Mule 4.9, RAML 1.0, APIKit, DataWeave, HTTP Connector, Maven, JavaScript, HTML, CSS

- Developed a RESTful currency API using Mule 4, RAML 1.0, and APIKit.
- Implemented `GET /api/currencies/{currency}` with APIKit routing and a Mule HTTP listener.
- Integrated the Mule flow with an external exchange-rate service and transformed the response to JSON.
- Implemented APIKit error handling for common client and routing failures.
- Built a responsive currency-conversion web UI with a complete currency catalogue, source/target selection, swap, live conversion, and connection testing.
- Configured the UI to derive its backend endpoint from the Mule listener configuration so users do not need to enter an API URL.
- Added architecture, API, UI, deployment, troubleshooting, and project documentation under `docs/`.
- Followed secure deployment guidance by keeping upstream provider credentials out of browser-delivered code.
