# Resume — Currency API Project

## MuleSoft Developer / Integration Engineer

### Currency API — Mule 4, RAML, APIKit, DataWeave, HTTP

- Designed and implemented a RESTful currency API using **Mule 4**, **RAML 1.0**, and **APIKit**.
- Defined the `GET /currencies/{currency}` resource and implemented APIKit routing through a Mule HTTP listener.
- Built the currency flow to read URI parameters and invoke an external exchange-rate service through Mule HTTP Request.
- Implemented structured API error handling for bad requests, missing resources, unsupported methods/media types, and other APIKit errors.
- Built a responsive browser-based currency explorer with source/target currency selection, amount conversion, swap, live API testing, and readable error states.
- Included the complete currency catalogue represented by the API example so the UI is not limited to a small hand-picked set of currencies.
- Automated frontend endpoint configuration from the Mule listener configuration so end users do not need to manually enter an API URL.
- Added project documentation covering architecture, API behavior, UI flow, deployment, troubleshooting, and resume-ready project details.
- Applied production-minded practices including CORS awareness, HTTPS guidance, and keeping upstream API credentials out of browser code.
